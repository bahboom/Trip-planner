# Orbit Trip Planner

A single-file trip planner: a rotatable globe over a galaxy backdrop, with two built-in budget itineraries
(Waterloo → Montréal → New York, and Narita → Hokkaido → Tokyo). Click any country to select it.

Open `index.html` in a browser. It loads d3 and topojson from cdnjs and fonts from Google Fonts, so it needs internet.

Prices and ratings are typical ranges, not live listings. Each item has "Check live" links (Google Maps, Booking.com,
Google Flights, Rome2Rio) so you can compare current prices before booking.

The "Plan my trip" button for new destinations only works when the page is opened inside Claude.
